# prompt-optimizer

Скилл для Claude.

Превращает сырое ТЗ в структурированный промпт для LLM через фреймворк As-Is → To-Be, а также ревьюит и докручивает готовые промпты. Учитывает литеральность современных моделей, параметры рассуждения и работу с инструментами. Для задач с множеством вариантов подключает diversity-protocol.

## Когда использовать

- Написать промпт из описания задачи
- Улучшить или отревьюить готовый промпт
- Собрать системный промпт

Не подходит для прямого выполнения задачи — если нужен сам пост или анализ, а не промпт.

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/prompt-optimizer.git ~/.claude/skills/prompt-optimizer
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `prompt-optimizer`.
